# 兼容范围与已知限制

截至 2026-09-13。这里区分维护者实测、代码适配与尚未验证，不把一个整合包的结果外推到全部环境。

| 环境/功能 | 状态 | 范围 |
|---|---|---|
| Minecraft 1.12.2 / Cleanroom / Java 21 | 维护者开发版本实测 | 新星工程隔离实例 |
| AE2 UEL v0.56.8-novaeng_ver + NEE | 指定组合实测 | AE 合成、补料续做、取料、合成样板编码 |
| 普通工作台批量合成 | 实测 | 数量、桶返还、工具耐久 |
| 书签、分组、材料偏好保存 | 实测 | 退出重进后保留 |
| 配方链与返还物计算 | 自动回归及部分实测 | 不代表覆盖所有模组的特殊合成事件 |
| 样板终端扩展槽位 | 已有适配及回归 | 不保证任意扩展终端通用 |
| 加工模式、流体/灌注样板编码 | 当前批量编码不覆盖 | 不能把材料显示支持等同于样板编码支持 |
| 机器加工自动执行 | 不属于普通九宫格执行能力 | 需要对应机器完成 |
| 流体/灌注材料直接取到背包 | 不支持通用直接取出 | Shift+T 面向可提取物品 |
| 其他 Forge 环境、AE 分支与多人服务器 | 待验证 | 不作兼容承诺 |
| AE2 Supergiant 等后续迁移目标 | 待独立适配验证 | 不能直接按 AE2 UEL 兼容结论使用 |

## 发布包验证边界

维护者已验证开发版 suite10 的 16 份 AE 合成、缺料补料续做、工作台批量、桶与工具返还，以及退出重进。公开 JAR 经独立构建，补入许可资源、修正版本元数据并移除多余的 `Tags 2.class`；未调整合成算法，但尚未对 GitHub 下载的最终 JAR 单独完成上述游戏内测试，因此 Release 保持 Pre-release。

稳定版候选应从 Release 重新下载安装并复验上述流程；记录加载的文件名、SHA256、环境版本及结果。文档更新不代表这些测试已经完成。

## 使用限制

- 与原 HEI/JEI 互斥，不能并装。
- 普通消耗型配方可以批处理，工具、容器和特殊事件仍需原生逻辑校验；不同配方速度可能不同。
- 材料明细中的流体以 mB 表示。旧 Mek 灌注资源不是通用流体，不能直接按桶换算。
- 书签显示排序不是执行队列。共享中间配方的显示、实际库存和执行剩余目标应分开理解。
- 多人服的服务端安装要求和权限行为尚未完整验证；不要假定仅替换客户端即可运行所有新增功能。

## brewing1 验证增量

维护者已确认正式实例中的药水数量修复正常。公开包由同一算法源码独立构建并包含发布许可资源，仍需区分开发安装包与公开包装；原有环境限制继续适用。四级酿造链的 1、3、4、16 瓶目标通过自动回归。
